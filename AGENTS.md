# Instrucciones para Codex

Las instrucciones de este repositorio viven en [CLAUDE.md](CLAUDE.md) y
aplican igual a Codex: léelo completo antes de trabajar. Incluye la
invariante de `core/` (verificada con `npm run check:boundary`), las reglas
de producto que no se negocian, de dónde sale la oferta de 3dev
(`npm run check:offer`) y lo que todavía no existe.

Este archivo es solo la entrada. Cambia las reglas en CLAUDE.md, no aquí:
una copia aparte se desfasa sin que nadie lo note.
