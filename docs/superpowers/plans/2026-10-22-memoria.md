# Memoria entre conversaciones (WhatsApp) — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** En WhatsApp, el asistente ve hasta 30 mensajes de los últimos 90 días anteriores a la conversación actual y los retoma sin inventar.

**Architecture:** `ConversationState.startedAt` separa "antes" de "ahora". La ruta de WhatsApp carga `earlier` de Postgres y lo pasa en `KnownContact`; `buildContactNote` lo agrega tras el breakpoint del caché. La web no recibe la nota (`stableContactId: false`).

**Tech Stack:** TypeScript, Next.js 15 route handlers, Supabase Postgres, Upstash Redis, Anthropic (Haiku 5.5).

**Spec:** `docs/superpowers/specs/2026-10-22-memoria-design.md`

## Global Constraints

- Solo WhatsApp: la memoria va en la nota de contacto, que solo existe con `stableContactId: true`.
- Máximo 30 mensajes, últimos 90 días, `at < startedAt`; cada mensaje recortado a 600 caracteres.
- Mensajes reales, nunca resúmenes generados.
- Una falla al cargar la memoria = contestar sin memoria (solo log).
- El motor no sabe de canales; `core/` no nombra clientes.
- Texto del aviso de privacidad exactamente el del spec.
- No `npm run build` con el dev server encendido. No subir ni desplegar sin Marco.

## Review Focus

1. **Persona que vuelve el mismo día (sesión viva)**: no se duplica lo que ya está en la sesión. → Task 2 (`earlier` respeta `before = startedAt`).
2. **Sesión vieja sin `startedAt`**: se fija una vez y no se mueve. → Task 1 (autoprueba del estado).
3. **Mensajes del dueño (handoff) en la memoria**: aparecen como "Team", no como el asistente. → Task 1.
4. **Historial muy largo o mensajes enormes**: tope de 30 y 600 caracteres. → Task 1 y Task 2.
5. **Persona sin historial que pregunta si la recuerdas**: no inventa. → Task 3 (eval).

- [ ] **Step 2: Implementar en `prompt.ts`**

```ts
export interface EarlierMessage {
  role: 'user' | 'assistant' | 'human';
  content: string;
  at: string;
}

/** The minimal state shape this needs, so the engine's own type stays in conversation.ts. */
interface StateWithStart { history: { role: string; content: string }[]; hasOffered: boolean; startedAt?: string }

/** When this conversation began: what came before it is memory, what came after is the session. Set once. */
export function withStart<S extends StateWithStart>(state: S, now: Date): S {
  return state.startedAt ? state : { ...state, startedAt: now.toISOString() };
}

const SPEAKER: Record<EarlierMessage['role'], string> = { user: 'Person', assistant: 'Assistant', human: 'Team' };
const EARLIER_CHARS = 600;

function earlierSection(earlier: EarlierMessage[], timeZone = 'UTC'): string {
  const day = (iso: string) =>
    new Intl.DateTimeFormat('en-CA', { timeZone, year: 'numeric', month: '2-digit', day: '2-digit' }).format(new Date(iso));
  const lines = earlier.map((m) => {
    const text = m.content.length > EARLIER_CHARS ? `${m.content.slice(0, EARLIER_CHARS - 1)}…` : m.content;
    return `[${day(m.at)}] ${SPEAKER[m.role]}: ${text.replace(/\s*\n\s*/g, ' ')}`;
  });
  return [
    '# Earlier conversations with this person',
    '',
    'What was said before this conversation, oldest first. "Team" is a person from the business who answered in person.',
    '',
    ...lines,
    '',
    'You may pick the thread back up and say, truthfully, that you remember what you talked about. State only what appears above; anything else you do not know. Prices or facts said before do not override the knowledge base: if they differ, the knowledge base is current. The one-offer rule still applies to this conversation.',
  ].join('\n');
}
```

`KnownContact` gana `earlier?: EarlierMessage[];`. `buildContactNote(contact, timeZone?)`: calcular `const memory = contact.earlier?.length ? `\n\n${earlierSection(contact.earlier, timeZone)}` : '';` y agregarlo al final de cada `return` que hoy regresa texto; donde hoy regresa `null` (sin datos ni teléfono), regresar `memory ? memory.trim() : null`.
