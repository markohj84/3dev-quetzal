# Handoff en vivo — plan de implementación

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** El dueño toma una conversación de WhatsApp desde el panel, contesta él (sale por el número del negocio), el asistente se calla ahí, y la conversación vuelve al asistente con un botón o sola a las 4 h.

**Architecture:** Tabla `handoffs` con RLS de escritura acotada; reglas puras en `core/handoff.ts`; la ruta de WhatsApp revisa la toma antes del motor; server actions del panel (sesión del usuario + RLS, envío a Meta en el servidor); refresco cada 5 s con `router.refresh()`.

**Tech Stack:** Next.js 15.5 (server actions, client component mínimo), `@supabase/ssr`, Supabase Postgres + RLS, WhatsApp Cloud API, Upstash Redis (sesión).

**Spec:** `docs/superpowers/specs/2026-10-21-handoff-design.md`

## Global Constraints

- Solo WhatsApp. Las conversaciones web no cambian.
- `HANDOFF_HOURS = 4`, `NOTIFY_EVERY_MINUTES = 15`, `WINDOW_HOURS = 24`, máximo 4096 caracteres por respuesta.
- El panel nunca usa `service_role`; la ruta de WhatsApp sí (ya lo hace vía `core/store/db.ts`).
- El dueño solo puede insertar `messages` con `role = 'human'` y solo en su cliente; `handoffs` solo en su cliente.
- El motor no sabe de tomas: la revisión vive en la ruta de WhatsApp.
- Una falla al leer `handoffs` en la ruta = "no tomada" (el asistente contesta).
- Un mensaje del dueño se guarda solo si Meta aceptó el envío.
- Ningún archivo bajo `core/` nombra a un cliente. Texto de cara al usuario en español.
- No `npm run build` con el dev server encendido. No subir ni desplegar sin Marco.

## Review Focus

1. **El dueño toma y la persona escribe varias veces seguidas**: llega un aviso, no uno por mensaje (tope de 15 min), y todos los mensajes quedan en la transcripción y en la sesión. → Task 1 (`shouldNotify`) y Task 4 (eval: dos mensajes, una marca `notified_at`).
2. **La toma venció mientras nadie miraba**: el siguiente mensaje lo contesta el asistente con el contexto de lo que dijo el dueño. → Task 4 (eval de toma vencida: la sesión ya trae el turno del dueño antes de contestar).
3. **Meta rechaza la respuesta del dueño** (token, número inválido, ventana): el dueño ve el motivo y no queda un mensaje "Tú" que nunca salió. → Task 5 (`check-panel-pages`).
4. **Otro usuario del panel, o de otro cliente, intenta tomar o escribir**: la base lo rechaza aunque arme la petición a mano. → Task 2 (`check-panel-rls`).
5. **La ventana de 24 h cerró**: el campo se desactiva y la acción también lo rechaza en el servidor. → Task 1 (`windowOpen`) y Task 5 (la acción revisa la ventana antes de llamar a Meta).

```ts
const HOUR_MS = 3600_000;

/** Taken while the owner keeps writing; four quiet hours hand it back, so nobody talks to a silent chat. */
export function isTaken(h: Handoff | null, now: Date): boolean {
  return !!h && now.getTime() - new Date(h.last_human_at).getTime() < HANDOFF_HOURS * HOUR_MS;
}

export function returnsAt(h: Handoff): Date {
  return new Date(new Date(h.last_human_at).getTime() + HANDOFF_HOURS * HOUR_MS);
}

/** Each alert is a paid WhatsApp template: one per quarter hour per conversation is enough to bring the owner back. */
export function shouldNotify(h: Handoff, now: Date): boolean {
  return !h.notified_at || now.getTime() - new Date(h.notified_at).getTime() >= NOTIFY_EVERY_MINUTES * 60_000;
}

/** Meta only lets the business write freely within 24 h of the person's last message. */
export function windowOpen(lastUserAt: string | null, now: Date): boolean {
  return !!lastUserAt && now.getTime() - new Date(lastUserAt).getTime() < WINDOW_HOURS * HOUR_MS;
}
```

```sql
-- 'human': what the owner wrote from the panel, so the transcript says who spoke.
alter table messages drop constraint messages_role_check;
alter table messages add constraint messages_role_check check (role in ('user', 'assistant', 'human'));

-- One row = the owner has this conversation; the assistant stays quiet in it
-- until last_human_at is four hours old (core/handoff.ts).
create table handoffs (
  client_id      text not null,
  contact_id     text not null,
  taken_by       uuid not null references auth.users on delete cascade,
  -- Another panel user's session cannot read auth.users, so the name travels here.
  taken_by_email text not null,
  taken_at       timestamptz not null default now(),
  last_human_at  timestamptz not null default now(),
  notified_at    timestamptz,
  primary key (client_id, contact_id),
  foreign key (client_id, contact_id) references contacts on delete cascade
);
alter table handoffs enable row level security;

create policy "panel maneja sus tomas" on handoffs for all to authenticated
  using (client_id in (select client_id from dashboard_users where user_id = (select auth.uid())))
  with check (client_id in (select client_id from dashboard_users where user_id = (select auth.uid())));

-- The owner may only add their own words: never the person's, never the assistant's.
create policy "panel escribe como humano" on messages for insert to authenticated
  with check (
    role = 'human'
    and client_id in (select client_id from dashboard_users where user_id = (select auth.uid()))
  );
```

```ts
/** first_seen_at is the first turn's time, set once: insert-or-ignore, then move last_seen_at forward. */
async function touchContact(clientId: string, contactId: string, channel: string, at: string): Promise<void> {
  const key = { client_id: clientId, contact_id: contactId };
  const created = await must(
    db()
      .from('contacts')
      .upsert({ ...key, channel, first_seen_at: at, last_seen_at: at }, { onConflict: 'client_id,contact_id', ignoreDuplicates: true })
      .select('contact_id'),
  );
  if (!created.length) {
    await must(db().from('contacts').update({ channel, last_seen_at: at }).match(key).lt('last_seen_at', at));
  }
}

export function createConversationLog(clientId: string): ConversationLog {
  return {
    async append(entry) {
      await touchContact(clientId, entry.contactId, entry.channel, entry.at.toISOString());
      await must(db().from('messages').insert(logEntryToMessages(clientId, entry)));
    },
    async appendInbound(entry) {
      const at = entry.at.toISOString();
      await touchContact(clientId, entry.contactId, entry.channel, at);
      await must(db().from('messages').insert({ client_id: clientId, contact_id: entry.contactId, role: 'user', content: entry.userText, at }));
    },
  };
}
```

```ts
export interface HandoffStore {
  get(contactId: string): Promise<Handoff | null>;
  release(contactId: string): Promise<void>;
  markNotified(contactId: string): Promise<void>;
}

/** The webhook's view of who has a conversation (service_role: the person writing has no session). */
export function createHandoffStore(clientId: string): HandoffStore {
  const row = (contactId: string) => db().from('handoffs').select('*').eq('client_id', clientId).eq('contact_id', contactId);
  return {
    async get(contactId) {
      return ((await must(row(contactId).maybeSingle())) as Handoff | null) ?? null;
    },
    async release(contactId) {
      await must(db().from('handoffs').delete().eq('client_id', clientId).eq('contact_id', contactId));
    },
    async markNotified(contactId) {
      await must(db().from('handoffs').update({ notified_at: new Date().toISOString() }).eq('client_id', clientId).eq('contact_id', contactId));
    },
  };
}
```

```ts
'use server';

import { redirect } from 'next/navigation';
import { getAssistant } from '../../../../assistant';
import { createPanelClient } from '../../../supabase';
import { requireAccess } from '../../../data';
import { windowOpen } from '../../../../../core/handoff';
import { createWhatsAppAdapter } from '../../../../../core/channels/whatsapp';
import { createSessionStore } from '../../../../../core/store/session-store';

const MAX_LENGTH = 4096;

async function context(contactId: string) {
  const { config } = await getAssistant();
  const sb = await createPanelClient();
  await requireAccess(sb, config.id);
  const { data: { user } } = await sb.auth.getUser();
  const { data: contact } = await sb.from('contacts').select('channel').eq('client_id', config.id).eq('contact_id', contactId).maybeSingle();
  // Only WhatsApp can carry the owner's words back to the person.
  if (contact?.channel !== 'whatsapp') throw new Error('handoff: only WhatsApp conversations can be taken');
  return { config, sb, user: user! };
}

const back = (contactId: string, aviso?: string) =>
  redirect(`/panel/conversaciones/${encodeURIComponent(contactId)}${aviso ? `?aviso=${encodeURIComponent(aviso)}` : ''}`);

export async function take(contactId: string) {
  const { config, sb, user } = await context(contactId);
  const now = new Date().toISOString();
  const { error } = await sb.from('handoffs').upsert(
    { client_id: config.id, contact_id: contactId, taken_by: user.id, taken_by_email: user.email ?? '', taken_at: now, last_human_at: now, notified_at: null },
    { onConflict: 'client_id,contact_id' },
  );
  back(contactId, error ? `No se pudo tomar: ${error.message}` : undefined);
}

export async function giveBack(contactId: string) {
  const { config, sb } = await context(contactId);
  await sb.from('handoffs').delete().eq('client_id', config.id).eq('contact_id', contactId);
  back(contactId);
}

export async function reply(contactId: string, form: FormData) {
  const { config, sb, user } = await context(contactId);
  const text = String(form.get('text') ?? '').trim();
  if (!text) back(contactId, 'Escribe un mensaje.');
  if (text.length > MAX_LENGTH) back(contactId, `WhatsApp acepta hasta ${MAX_LENGTH} caracteres.`);

  const { data: last } = await sb.from('messages').select('at').eq('client_id', config.id).eq('contact_id', contactId)
    .eq('role', 'user').order('at', { ascending: false }).limit(1).maybeSingle();
  if (!windowOpen(last?.at ?? null, new Date())) {
    back(contactId, 'WhatsApp solo deja escribir libremente 24 h después del último mensaje de la persona.');
  }

  try {
    await createWhatsAppAdapter({
      phoneNumberId: process.env.WHATSAPP_PHONE_NUMBER_ID ?? '',
      accessToken: process.env.WHATSAPP_ACCESS_TOKEN ?? '',
    }).deliver(contactId, { text });
  } catch (error) {
    // Nothing is saved: a "Tú" bubble for a message that never left would lie to the owner.
    const reason = String((error as Error).message).match(/"message":"([^"]+)"/)?.[1] ?? (error as Error).message;
    back(contactId, `No se pudo enviar: ${reason}`);
  }

  const now = new Date().toISOString();
  await sb.from('messages').insert({ client_id: config.id, contact_id: contactId, role: 'human', content: text, at: now });
  await sb.from('handoffs').upsert(
    { client_id: config.id, contact_id: contactId, taken_by: user.id, taken_by_email: user.email ?? '', last_human_at: now },
    { onConflict: 'client_id,contact_id' },
  );
  // The business said it: when the assistant takes over again, it sees this as its own side of the thread.
  const sessions = createSessionStore();
  const state = (await sessions.get(contactId)) ?? { history: [], hasOffered: false };
  await sessions.set(contactId, { ...state, history: [...state.history, { role: 'assistant', content: text }] });
  back(contactId);
}
```
